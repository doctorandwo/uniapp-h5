1. 查询异常列表
接口：GET /transportation/waybillAbnormal/selectAbnormalList
返回：BaseCommonlyEntity<AbnormalListVo>
入参（@QueryMap）：
参数	类型	必填	说明
handlerStatus	Int	是	处理状态
pageNum	Int	是	页码
pageSize	Int	是	每页条数（LIST_PAGE_SIZE）
driverSearch	String	否	司机/搜索关键字
waybillNo	String	否	运单号
响应字段 AbnormalListVo：companyName、description、fillTime、goodsBigTypeName、licenseNumber、loadAddressAlias、loadAttachmentCode、loadFormattedAddress、loadWeight、rejectReason、shipperName、signTime、status、stowageStatus、unloadAddressAlias、unloadAttachmentCode、unloadFormattedAddress、unloadWtight（注：原始字段名，应为 unloadWeight）、warningTime、waybillAbnormalCode、waybillCode、waybillNo、avatar、reson（异常原因：1接错单 2装卸磅单异 3无效运单 4轨迹异常 5操作异常 6其他 7运单疑似重复 8装货磅单异常 9卸货磅单异常 10自动核验轨迹异常）、isWarning（异常标记：0正常 1异常 2取消）。
